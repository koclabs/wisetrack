# WiseTrack · 手机与观看屏幕版

[English](README.md) · [Türkçe](README.tr.md) · [Español](README.es.md) · [العربية](README.ar.md) · [Русский](README.ru.md) · **中文** · [日本語](README.ja.md) · [한국어](README.ko.md)

WiseTrack 是一款在浏览器中运行的啮齿类动物行为跟踪软件。本文件夹是可在手机上像应用一样运行的网页版（PWA）。同一套文件可在 iPhone、Android、平板和电脑上运行。

| 文件 | 用途 |
|---|---|
| `index.html` | 执行跟踪的应用（在手机上打开） |
| `izle.html` | 观看屏幕：在电脑、电视浏览器或平板上打开，实时显示手机的画面和结果 |
| `sw.js`、`*.webmanifest`、`icons/` | 作为应用安装及离线使用 |
| `vendor/` | 投屏（PeerJS，MIT）和二维码（qrcode-generator，MIT）库 |
| `i18n/` | 界面翻译（英语、西班牙语、阿拉伯语、俄语、中文、日语、韩语） |

**界面语言：** Türkçe、English、Español、العربية、Русский、中文、日本語、한국어。在顶栏菜单中选择语言；详见[界面语言](#界面语言)。

## 1. 发布（一次，约 5 分钟）

手机浏览器只在 **https://** 地址下才能打开摄像头。直接把文件复制到手机上无法使用，需要将其放到一个免费的 https 地址上。

**GitHub Pages（推荐，长期且免费）**
1. 在 github.com 注册免费账户，用 **New repository** 创建一个*公开*仓库，例如 `wisetrack`。
2. 用 **Add file → Upload files** 拖入本文件夹的*内容*（index.html 位于最上层），然后点 **Commit**。
3. **Settings → Pages → Branch: main / (root) → Save**。一两分钟后，地址为 `https://用户名.github.io/wisetrack/`。

替代方案：把文件夹拖到 Netlify Drop（app.netlify.com/drop）也能得到 https 地址；若要长期保留，需要用免费账户认领。

更新时，重新上传文件并把 `sw.js` 中的 `VERSION` 值调大（例如从 `wisetrack-v13` 改为 `wisetrack-v14`）；手机会在下次打开应用时获取新版本。

## 2. 在手机上安装

- **iPhone / iPad：** 在 **Safari** 中打开地址 → 分享图标 → **添加到主屏幕**。首次启动时允许使用摄像头。
- **Android：** 在 **Chrome** 中打开地址 → 菜单 (⋮) → **安装应用**（或“添加到主屏幕”）。

安装后，跟踪无需联网即可使用。投屏需要联网。

## 3. 跟踪时手机的摆放

- 用三脚架或支架将手机固定在场地**正上方**；实验过程中不得移动或旋转。
- 使用**主（1×）后置摄像头**。超广角（0.5×）镜头或广角网络摄像头会使边缘弯曲；这种畸变可以用下面的**根据场地测量镜头畸变**校正，但主摄像头的画面仍然最干净。
- 调好光线后，点**锁定曝光和对焦**（在 Android 上可用；iPhone 浏览器不允许，请使用稳定、均匀的光线）。
- 长时间记录时请给手机充电。应用打开期间屏幕不会熄灭；若离开应用，为安全起见试验会暂停。

### 自动校准与摄像头校正

在 设置 > 测试装置与校准 中：

- **自动识别场地**：在场地为空时点击。应用从图像中央开始分离出地面，把场地的已知形状（方形、圆形或十字形）以亚像素精度拟合到边缘并放置各点。在圆形场地（水迷宫、Barnes）中，如果摄像头倾斜，圆心不会出现在椭圆中心；应用会根据摄像头几何计算出圆心。在十字迷宫中，封闭臂通过墙壁识别；如无法确定，可用**交换臂**纠正。如果墙壁与地面颜色相同，各点可能会贴到墙壁顶边上；应用检测到这种情况时会发出提示。
- **检查校准**：显示图像中场地边缘与模型的平均偏差（cm）（≤0.5 cm 为良好，>1.5 cm 请检查各点）。该值也会在每次试验开始时自动测量，并写入 Excel/CSV 摘要。
- **动物高度校正**（在“摄像头、镜头与动物高度”部分）：摄像头看到的是动物的背部，而不是它在地面上的位置。根据场地各点估计摄像头的高度和位置（如已实测高度请输入），并将跟踪点投影到地面上。不做校正时，即使摄像头位于正上方，靠近边缘的位置也会向外偏移，总距离约被高估 动物高度 /（摄像头高度 − 动物高度）（大鼠，摄像头高 75 cm：约 5.6%）。
- **根据场地测量镜头畸变**：无需棋盘格；应用会找出使场地直边变直（圆形场地的边缘变为椭圆）的畸变系数。
- **监测摄像头移动**（默认开启）：如果试验中摄像头或手机被碰到，场地边缘每秒与第一帧比较；一旦发现移动，各点与空场地参考会一起平移，并将该事件记录到摘要中。
- 如果动物的表观大小从场地一侧到另一侧明显变化（摄像头倾斜或各点偏移），结果中会出现警告。

用合成视频验证（摄像头位置、镜头畸变和大鼠大小均已知，跟踪高度 4 cm）：摄像头倾斜 18° 且畸变明显时，即使各点完全准确地手动放置，未校正的位置误差中位数为 1.3 cm、第 95 百分位为 3.1 cm，距离被高估 9.8%；使用自动校准 + 镜头 + 高度校正后，误差中位数为 0.16 cm、第 95 百分位为 0.8 cm，距离差为 0.2%。80° 广角摄像头：1.9 → 0.2 cm；水迷宫（摄像头高 220 cm）：0.34 → 0.26 cm；Barnes 迷宫：1.6 → 0.2 cm。试验中途摄像头移动 2 cm 时，未校正的误差中位数为 1.7 cm，开启移动监测后为 0.15 cm。

### 界面语言

顶栏的语言菜单提供 Türkçe（土耳其语）、English（英语）、Español（西班牙语）、العربية（阿拉伯语）、Русский（俄语）、中文、日本語（日语）和 한국어（韩语）。首次启动时使用浏览器语言（不支持时为英语）；选择会保存在设备上。更改语言后页面会重新加载。在链接后加上 `?lang=xx`（`en`、`tr`、`es`、`ar`、`ru`、`zh`、`ja`、`ko`）即可用指定语言打开应用。Excel/CSV 表头、区域名称以及图像上绘制的方位字也会使用所选语言；阿拉伯语界面从右向左排列。翻译位于 `i18n/` 文件夹（键为土耳其语原文）。

## 4. 投屏到其他屏幕

**应用自带的投屏（适用于所有设备）：** 在手机上进入 **投屏 → 开始投屏**。用平板摄像头扫描二维码，或在电脑/电视浏览器中打开 `…/izle.html` 并输入 6 位代码。带标注的实时画面、时间、区域表和距离会显示在那里。若开启“允许从观看屏幕开始/停止”，无需走近场地即可在那里控制试验。代码保存在手机上；在电视上把观看页面加入书签后，之后的实验会用同一代码连接。可同时连接多个屏幕。

工作原理：两台设备仅通过免费的 PeerJS 服务器相互发现；画面和数据在设备之间直接传输（WebRTC，加密）。如果单位网络阻止设备间连接，请打开手机的个人热点，并让观看设备连接到它。

| 手机 → | Mac | Windows 电脑 | 电视 | 平板 |

## 5. 导出结果

在“结果”页，**Excel (.xlsx)** 会在一个文件中生成四个工作表：*摘要*（指标与所用设置）、*区域*、*位置记录*（逐帧 X/Y、速度、区域）和*单行*（每只动物一行的结果，可直接粘贴到分组表中）。也提供 CSV 和 PNG 选项。在手机上，导出会打开分享菜单，可选择 Drive、文件或电子邮件。

## 6. 新物体识别（NOR）

在 设置 > 测试装置 中选择**物体识别**并设定阶段（适应 / 熟悉 / 测试）。物体已放入场地且没有动物时，点**自动识别物体**：识别出物体，同一帧也会保存为空场地参考（防止把物体误认为动物）。可在图像中拖动识别出的物体以移动，用白色方形手柄调整大小，更改形状（圆形/矩形），删除，或手动添加物体。在测试阶段，未选择哪个是新物体之前不会开始记录。

默认情况下，动物的**鼻尖点**距物体小于 2 cm 时计为探索；如果身体中心位于物体上方（爬上物体），不计为探索。鼻尖点根据体形（头端较窄）和运动方向估计，在屏幕上显示为青色圆点。结果给出每个物体的探索时间、探索次数和首次探索潜伏期；测试阶段还给出辨别指数 DI =（新 − 熟悉）/（新 + 熟悉）和识别指数 RI。鼻尖估计应通过若干人工评分的视频加以验证；必要时可将判定改为“中心点”。

**与动物颜色相同的物体。** 为避免把物体本身误认为动物，应用采取三项措施：(1) 使用实时摄像头且开启“检测到动物进入场地时开始”时，按下开始后会自动重新保存空场地（物体处于最终位置）；此时屏幕显示“正在保存空场地，请先不要放入动物”。(2) 随后逐一检查物体；若某物体在有空场地参考的情况下仍像动物（例如保存参考后被移动过，或视频没有参考），则在该次试验中将其排除在动物检测之外，并显示警告，同时写入 Excel 摘要。(3) 完全位于物体上的斑块永远不会被选为动物，除非动物刚刚在那里（爬上物体）。被排除的物体上无法识别爬上行为，且距物体 0.5 cm 以内的鼻尖不可见；因此探索时间可能略低。设置中的“始终将物体区域排除在动物检测之外”选项会在每次试验中应用同样的排除。

## 7. Morris 水迷宫（MWM）

在 设置 > 测试装置 中选择**水迷宫**，输入水池和平台直径，并选择阶段（训练 / 探测试验 / 可见）和起始点。将图像中的北、东、南、西四个点拖到池边的北、东、南、西标记上；在图像中把平台拖到实际位置。目标象限和对侧象限根据平台位置自动确定。没有动物时，用 检测 > **保存空场地** 保存空水池；这样水面上固定的反光不会被误认为动物。选择水迷宫后，试验时长设为 60 秒。

- **训练与可见平台：** 动物中心点进入平台区域并停留设定时间（默认 2 秒）后，试验自动结束。给出逃避潜伏期（首次到达平台）、是否找到平台、路径长度、路径效率（起点到平台的直线距离 / 游泳距离）、目标象限停留时间、到平台的平均距离、贴壁时间（趋触性）和游泳速度。若时间用完仍未找到平台，逃避潜伏期记为试验时长。
- **探测试验：** 给出在目标象限和对侧象限停留时间的百分比、穿越平台位置的次数、首次到达平台位置的时间以及到平台的平均距离。穿越平台位置不应用区域切换时间。

在 Excel 文件的*单行*工作表中，“目标象限”和“对侧象限”列对每只动物使用相同名称，因此即使各组平台位置不同，结果也可上下粘贴。

## 8. Barnes 迷宫

在 设置 > 测试装置 中选择 **Barnes 迷宫**；输入平台直径、孔数、孔直径以及孔中心到平台边缘的距离（默认小鼠平台：92 cm、20 个孔、5 cm）。将北、东、南、西四个点拖到平台边缘；**北点必须与 1 号孔对齐**，孔按顺时针编号。若绘制的孔环与图像中的孔不重合，点**自动对齐孔**或用滑块旋转。在列表中选择目标（逃生）孔，或在图像中点按该孔。没有动物时，用 检测 > **保存空场地** 保存空平台；否则深色的孔（尤其是黑色动物时）可能被误认为动物。选择 Barnes 后，试验时长设为 180 秒。

- **孔访问：** 动物鼻尖点接近孔边缘 1 cm 以内（可调）时计为一次访问。每次访问非目标孔都是一次错误；重复访问同一孔也计入。
- **训练：** 给出初级潜伏期、初级错误和初级路径（直到首次访问目标孔），以及总潜伏期、总错误和总路径（直到动物进入逃生箱）。动物在目标孔旁从图像中消失 1 秒（可调）时，视为已进入逃生箱，试验结束；消失时刻即总潜伏期。
- **探测试验：** 给出对目标孔和其他孔的访问次数、目标孔访问比例、目标象限停留时间以及各初级指标。
- **搜索策略**自动给出建议：*直接*（最多 3 次错误，且均距目标 2 孔以内）、*连续*（沿同一方向连续访问至少 3 个相邻孔），其余为*随机*。孔访问顺序写入 Excel 摘要；应据此顺序核对建议。

在 Excel 文件的*单行*工作表中，孔的列名为“孔 1 … 孔 N”，象限列为“目标象限”、“对侧象限”和两个相邻象限，因此即使目标孔因动物而异，结果也可上下粘贴。

## 9. MPG、AVI 及其他视频格式

浏览器可直接打开 MP4（H.264）、MOV 和 WebM 视频。选择 MPG/MPEG（MPEG-1/2）、VOB、AVI、WMV、FLV、TS/MTS 等格式时，应用会显示**转换为 MP4 并打开**按钮。转换完全在设备上用 ffmpeg.wasm 完成；视频不会发送到任何地方。转换器（约 32 MB）在首次使用时从 jsDelivr 下载并保存在浏览器缓存中，因此首次转换需要联网。隔行扫描的 DVR/DVD 录像会自动去隔行，图像宽度最多缩小到 960 像素。在电脑上，1 分钟的标清视频约半分钟即可转换完成；在手机上较慢。若用**保存转换后的视频**保存转换后的文件，再次分析同一视频时就无需重新转换。

ffmpeg.wasm（@ffmpeg/core 0.12.10）采用 GPL-2.0-or-later 许可证；应用仅在运行时从 CDN 加载它。源代码：https://github.com/ffmpegwasm/ffmpeg.wasm

### 分析速度

分析视频时，速度选项是一个上限。由于浏览器每秒最多只能提供与屏幕刷新率相同数量的帧（通常为 60），而繁忙的设备还可能丢帧，应用会自行调整速度，确保处理每一帧：不丢帧时加速，一旦丢帧就减速。分析结束后会显示平均速度和跳帧比例，并写入 Excel/CSV 摘要；若比例超过 1%，应以更低的速度上限重新分析。平滑按时间而非帧数进行，因此同一视频无论以何种速度分析，结果都相同。

### 批量视频分析

“设置”页末尾的 **5 · 批量视频分析** 卡片会依次分析在同一装置下拍摄的视频：

1. 用**添加视频**选择多个视频（在电脑上也可将其拖放到卡片上）。列表按文件名排序；动物编号取自文件名，可在表格中修改。在物体识别中可为每一行单独选择新物体，在水迷宫中可单独选择起始点。
2. 用**打开第一个视频进行设置**一次性设置场地（物体识别中还有物体）、阈值和时长。
3. 选项：**场地位置**可在所有视频中相同，也可在每个视频中自动识别（若摄像头在不同视频之间移动过）。**空场地参考**默认从每个视频本身提取：在分布于整个视频的 21 帧中，动物在每个位置只出现在少数几帧里，因此每个像素的第 30 百分位（白化动物）或第 70 百分位（深色动物）即为没有动物的地面。
4. **开始批量分析**。MPG/AVI 等格式轮到时会自动转换。无法打开或找不到动物的视频会被标记并跳过；分析不会停止。用**停止**中断的列表可用**分析剩余视频**继续。
5. 完成后，在电脑上**批量 Excel** 文件会自动下载（在手机上点按按钮）。工作表：*批量结果*（每个视频一行，包含单视频 Excel 中的全部指标）、*区域*（长格式）、*质量*（检测到/跳过的帧、校准偏差、摄像头移动、警告）、*设置*，以及可选的*位置记录*。

分析期间，该标签页必须保持打开并处于前台，因为浏览器不会向后台标签页提供视频帧。若标签页转入后台，分析会暂停，返回后从中断处继续。屏幕不会自动熄灭。

## 10. 离线单文件版（用于电脑）

`wisetrack.html` 也单独提供：下载到电脑后双击，即可在 Chrome 或 Edge 中打开；无需安装、联网或账户。包括摄像头、视频分析、Excel 导出和所有界面语言在内的全部功能均可使用；此版本仅关闭了应用内投屏，转换 MPG 等格式需要联网。由于下载的 HTML 文件在手机上无法可靠打开，在手机上请使用网址并添加到主屏幕。

## 11. 自建信令服务器（可选）

如果无法访问公共 PeerJS 服务器，或希望留在单位内部网络，可在网络中的一台电脑上运行 `npx peer --port 9000`，并在两个页面的地址后加上 `?ps=服务器IP:9000`（若没有 https，再加上 `&pss=0`）。
