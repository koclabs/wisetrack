# WiseTrack · 휴대폰 및 보기 화면 버전

[English](README.md) · [Türkçe](README.tr.md) · [Español](README.es.md) · [العربية](README.ar.md) · [Русский](README.ru.md) · [中文](README.zh.md) · [日本語](README.ja.md) · **한국어**

**▶ 앱 열기: [koclabs.github.io/wisetrack](https://koclabs.github.io/wisetrack/)** — 휴대폰, 태블릿, 컴퓨터의 브라우저에서 실행되며 설치가 필요 없습니다. 휴대폰에서는 홈 화면에 추가하세요(2절). 1절은 직접 사본을 호스팅하려는 경우에만 필요합니다.

WiseTrack은 브라우저에서 실행되는 설치류 행동 추적 소프트웨어입니다. 이 폴더는 휴대폰에서 앱처럼 실행되는 웹 버전(PWA)입니다. 같은 파일이 iPhone, Android, 태블릿, 컴퓨터에서 작동합니다.

| 파일 | 역할 |
|---|---|
| `index.html` | 추적을 수행하는 앱 (휴대폰에서 엶) |
| `izle.html` | 보기 화면: PC, TV 브라우저 또는 태블릿에서 열며, 휴대폰의 영상과 결과를 실시간으로 보여 줌 |
| `sw.js`, `*.webmanifest`, `icons/` | 앱으로 설치 및 오프라인 사용 |
| `vendor/` | 미러링(PeerJS, MIT) 및 QR 코드(qrcode-generator, MIT) 라이브러리 |
| `i18n/` | 인터페이스 번역 (영어, 스페인어, 아랍어, 러시아어, 중국어, 일본어, 한국어) |

**지원 인터페이스 언어:** Türkçe, English, Español, العربية, Русский, 中文, 日本語, 한국어. 언어는 상단 막대의 메뉴에서 고릅니다. 자세한 내용은 [인터페이스 언어](#인터페이스-언어) 항목을 보세요.

## 버전과 인용

논문에서 분석한 버전(v10)은 Zenodo에 보관되어 있습니다(DOI [10.5281/zenodo.24535051](https://doi.org/10.5281/zenodo.24535051), 커밋 [`0704db8`](https://github.com/koclabs/wisetrack/tree/0704db8)). 이후 버전에는 자동 보정과 카메라 보정(v11), 동영상 일괄 분석(v12), 추가 인터페이스 언어(v13)가 더해졌습니다. 논문의 분석을 재현하려면 보관된 버전을 사용하세요.

WiseTrack은 MIT 라이선스로 공개됩니다(`LICENSE` 참조). 인용 정보는 `CITATION.cff`에 있습니다.

## 1. 게시 (한 번, 약 5분)

휴대폰 브라우저는 **https://** 주소에서만 카메라를 엽니다. 파일을 휴대폰에 바로 복사해서는 작동하지 않으므로, 무료 https 주소에 올려야 합니다.

**GitHub Pages (권장, 영구적이고 무료)**
1. github.com에서 무료 계정을 만들고 **New repository**로 *공개* 저장소(예: `wisetrack`)를 만듭니다.
2. **Add file → Upload files**로 이 폴더의 *내용*(index.html이 최상위에 오도록)을 끌어 놓고 **Commit**을 누릅니다.
3. **Settings → Pages → Branch: main / (root) → Save**. 1~2분 뒤 주소는 `https://사용자이름.github.io/wisetrack/`이 됩니다.

대안: 폴더를 Netlify Drop(app.netlify.com/drop)에 끌어 놓아도 https 주소를 얻을 수 있습니다. 영구적으로 쓰려면 무료 계정으로 등록해야 합니다.

업데이트할 때는 파일을 다시 올리고 `sw.js`의 `VERSION` 값을 올리세요(예: `wisetrack-v13`에서 `wisetrack-v14`로). 휴대폰은 다음에 앱을 열 때 새 버전을 받습니다.

## 2. 휴대폰에 설치

- **iPhone / iPad:** **Safari**에서 주소를 열고 → 공유 아이콘 → **홈 화면에 추가**. 처음 실행할 때 카메라 접근을 허용하세요.
- **Android:** **Chrome**에서 주소를 열고 → 메뉴(⋮) → **앱 설치**(또는 '홈 화면에 추가').

설치 후에는 인터넷 없이도 추적이 작동합니다. 미러링에는 인터넷이 필요합니다.

## 3. 추적을 위한 휴대폰 배치

- 삼각대나 거치대로 휴대폰을 아레나 **바로 위**에 고정하세요. 실험 중에 움직이거나 회전해서는 안 됩니다.
- **기본(1×) 후면 카메라**를 사용하세요. 초광각(0.5×) 렌즈나 광각 웹캠은 가장자리를 휘어 보이게 합니다. 이 왜곡은 아래의 **아레나로 렌즈 왜곡 측정**으로 보정할 수 있지만, 기본 카메라가 여전히 가장 깨끗한 영상을 줍니다.
- 조명을 맞춘 뒤 **노출과 초점 고정**을 누르세요(Android에서 작동합니다. iPhone 브라우저는 허용하지 않으므로 일정하고 고른 조명을 사용하세요).
- 긴 세션에서는 휴대폰을 충전기에 연결해 두세요. 앱이 열려 있는 동안 화면이 꺼지지 않으며, 앱에서 나가면 안전을 위해 세션이 일시 중지됩니다.

### 자동 보정과 카메라 보정

설정 > 시험 장치와 보정 에서:

- **아레나 자동 찾기**: 아레나가 비어 있을 때 누르세요. 앱이 영상 가운데에서 시작해 바닥을 분리하고, 아레나의 알려진 모양(정사각형, 원, 십자형)을 서브픽셀 정밀도로 가장자리에 맞춰 점을 배치합니다. 원형 아레나(수중 미로, 반즈)에서 카메라가 기울어 있으면 원의 중심이 타원의 중심에 나타나지 않는데, 앱이 카메라 기하로 중심을 계산합니다. 십자 미로에서는 닫힌 팔을 벽으로 알아봅니다. 확실하지 않으면 **팔 바꾸기**로 바로잡으세요. 벽이 바닥과 같은 색이면 점이 벽 윗모서리에 맞춰질 수 있으며, 앱은 이를 감지하면 경고합니다.
- **보정 확인**: 영상 속 아레나 가장자리가 모델에서 평균 몇 cm 벗어나는지 보여 줍니다(0.5 cm 이하 양호, 1.5 cm 초과 시 점 확인). 이 값은 매 시행을 시작할 때도 자동으로 측정되어 Excel/CSV 요약에 기록됩니다.
- **동물 높이 보정**('카메라, 렌즈, 동물 높이' 항목): 카메라는 바닥 위의 위치가 아니라 동물의 등을 봅니다. 아레나 점으로 카메라 높이와 위치를 추정하고(높이를 실측했다면 입력하세요) 추적점을 바닥에 투영합니다. 보정하지 않으면 카메라가 바로 위에 있어도 가장자리 근처의 위치가 바깥쪽으로 밀리고, 총 이동 거리가 대략 동물 높이 / (카메라 높이 − 동물 높이)만큼 과대 추정됩니다(랫드, 카메라 높이 75 cm: 약 5.6%).
- **아레나로 렌즈 왜곡 측정**: 체커보드가 필요 없습니다. 아레나의 곧은 가장자리가 곧게(원형 아레나에서는 가장자리가 타원이) 되는 왜곡 계수를 찾습니다.
- **카메라 이동 감시**(기본으로 켜짐): 시행 중에 카메라나 휴대폰이 부딪혀 움직이면 아레나 가장자리를 매초 첫 프레임과 비교합니다. 이동이 발견되면 점과 빈 아레나 기준을 함께 옮기고, 그 사건을 요약에 기록합니다.
- 동물의 겉보기 크기가 아레나 한쪽에서 다른 쪽까지 뚜렷하게 달라지면(카메라 기울어짐 또는 점 이동) 결과에 경고가 나타납니다.

합성 동영상으로 검증한 결과(카메라 위치, 렌즈 왜곡, 랫드 크기를 알고 있음, 추적 높이 4 cm): 카메라가 18° 기울고 왜곡이 뚜렷한 조건에서는 점을 손으로 정확히 놓아도 보정하지 않은 위치 오차가 중앙값 1.3 cm, 95번째 백분위 3.1 cm였고 이동 거리는 9.8% 과대 추정되었습니다. 자동 보정 + 렌즈 + 높이 보정을 쓰면 오차는 중앙값 0.16 cm, 95번째 백분위 0.8 cm, 이동 거리 차이는 0.2%였습니다. 80° 광각 카메라에서는 1.9 → 0.2 cm, 수중 미로(카메라 높이 220 cm)에서는 0.34 → 0.26 cm, 반즈 미로에서는 1.6 → 0.2 cm였습니다. 시행 도중 카메라가 2 cm 이동했을 때 오차 중앙값은 보정 없이 1.7 cm, 이동 감시를 켜면 0.15 cm였습니다.

### 인터페이스 언어

상단 막대의 언어 메뉴에서 Türkçe(터키어), English(영어), Español(스페인어), العربية(아랍어), Русский(러시아어), 中文(중국어), 日本語(일본어), 한국어를 고를 수 있습니다. 처음 실행할 때는 브라우저 언어를 사용하며(지원하지 않으면 영어), 선택한 언어는 기기에 기억됩니다. 언어를 바꾸면 페이지가 다시 로드됩니다. 링크에 `?lang=xx`(`en`, `tr`, `es`, `ar`, `ru`, `zh`, `ja`, `ko`)를 붙이면 해당 언어로 앱을 열 수 있습니다. Excel/CSV 머리글, 구역 이름, 영상에 그려지는 방위 글자도 선택한 언어를 따르며, 아랍어 인터페이스는 오른쪽에서 왼쪽으로 배치됩니다. 번역은 `i18n/` 폴더에 있습니다(키는 터키어 원문입니다).

## 4. 다른 화면으로 미러링

**앱 자체 미러링(모든 기기에서 작동):** 휴대폰에서 **미러링 → 미러링 시작**을 누르세요. 표시된 QR 코드를 태블릿 카메라로 스캔하거나, 컴퓨터나 TV 브라우저에서 `…/izle.html`을 열고 6자리 코드를 입력하세요. 표시가 붙은 실시간 영상, 시간, 구역 표, 이동 거리가 그곳에 나타납니다. '보기 화면에서 시작/중지 허용'을 켜면 아레나에 다가가지 않고도 그곳에서 시행을 조작할 수 있습니다. 코드는 휴대폰에 저장되며, TV에서 보기 페이지를 한 번 북마크해 두면 이후 실험에서도 같은 코드로 연결됩니다. 여러 화면을 동시에 연결할 수 있습니다.

작동 방식: 두 기기는 무료 PeerJS 서버를 통해 서로를 찾기만 하고, 영상과 데이터는 기기 사이에서 직접(WebRTC, 암호화) 전송됩니다. 기관 네트워크가 기기 간 연결을 막으면 휴대폰의 개인용 핫스팟을 켜고 보기 기기를 거기에 연결하세요.

**운영 체제 미러링(추가 선택 사항):**

| 휴대폰 → | Mac | Windows PC | TV | 태블릿 |
|---|---|---|---|---|
| iPhone | AirPlay (macOS 12 이상) | izle.html | Apple TV / AirPlay 2 지원 TV | izle.html |
| Android | scrcpy (USB, 무료) | scrcpy (USB, 무료) | 전송 / Smart View / Chromecast | izle.html |

## 5. 결과 내보내기

결과 탭의 **Excel (.xlsx)**은 한 파일에 네 개의 시트를 만듭니다: *요약*(지표와 사용한 설정), *구역*, *위치 기록*(프레임별 X/Y, 속도, 구역), *한 줄*(동물마다 한 줄 결과로, 그룹 표에 바로 붙여 넣을 수 있음). CSV와 PNG 옵션도 있습니다. 휴대폰에서는 내보내기를 하면 공유 메뉴가 열려 Drive, 파일, 이메일 등을 고를 수 있습니다.

## 6. 새 물체 인식 (NOR)

설정 > 시험 장치에서 **물체 인식**을 고르고 단계(습관화 / 익숙화 / 시험)를 정하세요. 물체가 아레나에 있고 동물이 없을 때 **물체 자동 찾기**를 누르면 물체를 찾고, 같은 프레임을 빈 아레나 기준으로 저장합니다(물체가 동물로 오인되는 것을 막습니다). 찾은 물체는 영상에서 끌어 옮기거나, 흰색 사각형 핸들로 크기를 바꾸거나, 모양(원/직사각형)을 바꾸거나, 삭제하거나, 직접 추가할 수 있습니다. 시험 단계에서는 어느 물체가 새것인지 고르기 전까지 기록이 시작되지 않습니다.

기본적으로 동물의 **코 지점**이 물체에서 2 cm 안에 있으면 탐색으로 계산합니다. 몸 중심이 물체 위에 있으면(올라간 경우) 탐색으로 계산하지 않습니다. 코 지점은 몸 모양(머리 쪽이 더 좁음)과 이동 방향으로 추정하며, 화면에는 청록색 점으로 표시됩니다. 결과에는 물체마다 탐색 시간, 탐색 횟수, 첫 탐색 잠복기가 나오고, 시험 단계에서는 변별 지수 DI = (새것 − 익숙한 것) / (새것 + 익숙한 것)와 인식 지수 RI가 나옵니다. 코 추정은 손으로 채점한 동영상 몇 개와 비교해 검증해야 하며, 필요하면 기준을 '중심점'으로 바꿀 수 있습니다.

**동물과 같은 색의 물체.** 물체 자체가 동물로 오인되지 않도록 앱은 세 가지 조치를 취합니다. (1) 실시간 카메라에서 '아레나에서 동물이 검출되면 시작'이 켜져 있을 때 시작을 누르면, 빈 아레나(물체가 최종 위치에 있는 상태)를 자동으로 다시 저장합니다. 그동안 화면에는 '빈 아레나를 저장하는 중입니다. 아직 동물을 넣지 마세요'라고 표시됩니다. (2) 이어서 각 물체를 확인합니다. 빈 아레나 기준이 있는데도 여전히 동물처럼 보이는 물체(예: 기준 저장 후 옮겨졌거나 동영상에 기준이 없는 경우)는 그 시행에서 동물 검출에서 제외되고, 경고가 표시되며, Excel 요약에 기록됩니다. (3) 완전히 물체 위에 있는 덩어리는 동물이 방금 그곳에 있었던 경우(올라간 경우)를 제외하고는 결코 동물로 선택되지 않습니다. 제외된 물체에서는 올라가는 행동을 구별할 수 없고, 물체에서 0.5 cm 안의 코끝은 보이지 않으므로 탐색 시간이 다소 낮게 나올 수 있습니다. 설정의 '물체 영역을 항상 동물 검출에서 제외' 옵션은 모든 시행에 같은 제외를 적용합니다.

## 7. 모리스 수중 미로 (MWM)

설정 > 시험 장치에서 **수중 미로**를 고르고, 수조와 플랫폼 지름을 입력하고, 단계(학습 / 탐색 시험 / 보이는 플랫폼)와 출발점을 고르세요. 영상의 북, 동, 남, 서 점을 수조 가장자리의 각 방위 표시로 끌어 놓고, 영상에서 플랫폼을 실제 위치로 끌어 놓으세요. 목표 사분면과 반대 사분면은 플랫폼 위치로 자동으로 정해집니다. 동물이 없을 때 검출 > **빈 아레나 저장**으로 빈 수조를 저장하세요. 그러면 수면의 고정된 빛 반사가 동물로 오인되지 않습니다. 수중 미로를 고르면 시행 시간이 60초로 설정됩니다.

- **학습과 보이는 플랫폼:** 동물 중심점이 플랫폼 영역에 들어가 설정 시간(기본 2초) 동안 머물면 시행이 자동으로 끝납니다. 도피 잠복기(플랫폼 첫 도착), 플랫폼 발견 여부, 경로 길이, 경로 효율(출발점에서 플랫폼까지 직선 거리 / 헤엄친 거리), 목표 사분면 체류 시간, 플랫폼까지 평균 거리, 벽 근처 체류 시간(주촉성), 수영 속도가 나옵니다. 시간 안에 플랫폼을 찾지 못하면 도피 잠복기는 시행 시간으로 기록됩니다.
- **탐색 시험:** 목표 사분면과 반대 사분면 체류 시간 비율, 플랫폼 위치 통과 횟수, 플랫폼 위치 첫 도착 시간, 플랫폼까지 평균 거리가 나옵니다. 플랫폼 위치 통과에는 구역 전환 시간을 적용하지 않습니다.

Excel 파일의 *한 줄* 시트에서는 '목표 사분면'과 '반대 사분면' 열 이름이 모든 동물에서 같으므로, 그룹마다 플랫폼 위치가 달라도 결과를 위아래로 붙여 넣을 수 있습니다.

## 8. 반즈 미로

설정 > 시험 장치에서 **반즈 미로**를 고르고, 플랫폼 지름, 구멍 수, 구멍 지름, 구멍 중심에서 플랫폼 가장자리까지 거리를 입력하세요(기본 마우스 플랫폼: 92 cm, 구멍 20개, 5 cm). 북, 동, 남, 서 점을 플랫폼 가장자리로 끌어 놓으세요. **북 점은 1번 구멍과 일직선이어야 하며**, 구멍은 시계 방향으로 번호가 매겨집니다. 그려진 구멍 고리가 영상의 구멍과 맞지 않으면 **구멍 자동 정렬**을 누르거나 슬라이더로 돌리세요. 목표(탈출) 구멍은 목록에서 고르거나 영상에서 구멍을 눌러 정하세요. 동물이 없을 때 검출 > **빈 아레나 저장**으로 빈 플랫폼을 저장하세요. 그렇지 않으면 어두운 구멍(특히 검은 동물일 때)이 동물로 오인될 수 있습니다. 반즈를 고르면 시행 시간이 180초로 설정됩니다.

- **구멍 방문:** 동물의 코 지점이 구멍 가장자리에서 1 cm(조절 가능) 안으로 다가가면 방문으로 계산합니다. 목표가 아닌 구멍 방문은 모두 오류이며, 같은 구멍을 반복 방문한 것도 계산합니다.
- **학습:** 1차 잠복기, 1차 오류, 1차 경로(목표 구멍 첫 방문까지)와 총 잠복기, 총 오류, 총 경로(동물이 탈출 상자에 들어갈 때까지)가 나옵니다. 동물이 목표 구멍 옆에서 1초(조절 가능) 동안 영상에서 사라지면 탈출 상자에 들어간 것으로 보고 시행이 끝나며, 사라진 순간이 총 잠복기입니다.
- **탐색 시험:** 목표 구멍과 다른 구멍 방문 횟수, 목표 구멍 방문 비율, 목표 사분면 체류 시간, 1차 지표가 나옵니다.
- **탐색 전략**은 자동으로 제안됩니다: *직접*(오류 3회 이하, 모두 목표에서 2구멍 이내), *연속*(한 방향으로 이웃 구멍 3개 이상 연달아), 나머지는 *무작위*. 구멍 방문 순서가 Excel 요약에 기록되므로, 제안은 이 순서로 확인해야 합니다.

Excel 파일의 *한 줄* 시트에서는 구멍 열 이름이 '구멍 1 … 구멍 N', 사분면 열 이름이 '목표 사분면', '반대 사분면'과 두 인접 사분면이므로, 동물마다 목표 구멍이 달라도 결과를 위아래로 붙여 넣을 수 있습니다.

## 9. MPG, AVI 및 기타 동영상 형식

브라우저는 MP4(H.264), MOV, WebM 동영상을 바로 엽니다. MPG/MPEG(MPEG-1/2), VOB, AVI, WMV, FLV, TS/MTS 같은 형식을 고르면 앱이 **MP4로 변환하여 열기** 버튼을 보여 줍니다. 변환은 ffmpeg.wasm으로 전적으로 기기에서 이루어지며 동영상은 어디에도 전송되지 않습니다. 변환기(약 32 MB)는 처음 사용할 때 jsDelivr에서 내려받아 브라우저 캐시에 남으므로, 첫 변환에는 인터넷이 필요합니다. 인터레이스 DVR/DVD 녹화본은 자동으로 디인터레이스되고, 영상은 최대 960픽셀 너비로 줄어듭니다. 컴퓨터에서는 1분짜리 표준 화질 동영상이 약 30초 만에 변환되며, 휴대폰에서는 더 느립니다. 변환된 파일을 **변환된 동영상 저장**으로 저장해 두면 같은 동영상을 다시 분석할 때 다시 변환할 필요가 없습니다.

ffmpeg.wasm(@ffmpeg/core 0.12.10)은 GPL-2.0-or-later 라이선스이며, 앱은 실행 시 CDN에서 불러오기만 합니다. 소스 코드: https://github.com/ffmpegwasm/ffmpeg.wasm

### 분석 속도

동영상을 분석할 때 속도 옵션은 상한값입니다. 브라우저가 초당 넘겨줄 수 있는 프레임 수는 화면 재생률(보통 60)까지이고, 바쁜 기기는 프레임을 놓칠 수도 있으므로, 앱은 모든 프레임을 처리하도록 속도를 스스로 조절합니다. 프레임을 놓치지 않는 동안은 빨라지고, 놓치는 순간 느려집니다. 분석이 끝나면 평균 속도와 건너뛴 프레임 비율이 표시되고 Excel/CSV 요약에도 기록됩니다. 비율이 1%를 넘으면 더 낮은 속도 상한으로 다시 분석해야 합니다. 평활화는 프레임 수가 아니라 시간 기준으로 적용되므로, 같은 동영상은 어떤 속도로 분석해도 같은 결과를 냅니다.

### 동영상 일괄 분석

설정 탭 끝의 **5 · 동영상 일괄 분석** 카드는 같은 장치로 촬영한 동영상을 차례로 분석합니다:

1. **동영상 추가**로 여러 동영상을 고르세요(컴퓨터에서는 카드 위로 끌어다 놓을 수도 있습니다). 목록은 파일 이름 순으로 정렬되며, 동물 코드는 파일 이름에서 가져오고 표에서 바꿀 수 있습니다. 물체 인식에서는 새 물체를, 수중 미로에서는 출발점을 줄마다 따로 고를 수 있습니다.
2. **설정을 위해 첫 동영상 열기**로 아레나(물체 인식에서는 물체도), 임계값, 시간을 한 번 설정하세요.
3. 옵션: **아레나 배치**는 모든 동영상에서 같게 하거나 동영상마다 자동으로 찾을 수 있습니다(동영상 사이에 카메라가 움직였다면). **빈 아레나 기준**은 기본적으로 각 동영상에서 추출합니다. 동영상 전체에 퍼진 21개 프레임에서 동물은 각 지점에 몇 개 프레임에만 나타나므로, 각 픽셀의 30번째 백분위(알비노 동물) 또는 70번째 백분위(어두운 동물)가 동물 없는 바닥이 됩니다.
4. **일괄 분석 시작**. MPG/AVI 같은 형식은 차례가 오면 자동으로 변환됩니다. 열 수 없거나 동물을 찾지 못한 동영상은 표시하고 건너뛰며, 분석은 멈추지 않습니다. **중지**로 끊은 목록은 **나머지 분석**으로 이어 갈 수 있습니다.
5. 끝나면 컴퓨터에서는 **일괄 Excel** 파일이 자동으로 내려받아집니다(휴대폰에서는 버튼을 누르세요). 시트: *일괄 결과*(동영상마다 한 줄, 단일 동영상 Excel의 모든 지표), *구역*(긴 형식), *품질*(검출/건너뛴 프레임, 보정 편차, 카메라 이동, 경고), *설정*, 그리고 선택적으로 *위치 기록*.

분석하는 동안 탭은 열려 있고 앞에 있어야 합니다. 브라우저는 백그라운드 탭에 동영상 프레임을 넘겨주지 않기 때문입니다. 탭이 백그라운드로 가면 분석이 일시 중지되고, 돌아오면 멈춘 곳부터 이어집니다. 화면은 저절로 꺼지지 않습니다.

## 10. 오프라인 단일 파일 버전 (컴퓨터용)

`wisetrack.html`도 따로 제공됩니다. 컴퓨터에 내려받아 두 번 클릭하면 Chrome이나 Edge에서 열립니다. 설치, 인터넷, 계정이 필요 없습니다. 카메라, 동영상 분석, Excel 내보내기, 모든 인터페이스 언어를 포함해 모든 기능이 작동합니다. 이 버전에서는 앱 내 미러링만 꺼져 있으며, MPG 같은 형식을 변환하려면 인터넷이 필요합니다. 내려받은 HTML 파일은 휴대폰에서 안정적으로 열리지 않으므로, 휴대폰에서는 웹 주소를 열고 홈 화면에 추가하는 방법을 쓰세요.

## 11. 자체 시그널링 서버 (선택)

공개 PeerJS 서버에 접속할 수 없거나 기관 내부에서만 쓰고 싶다면, 네트워크의 컴퓨터에서 `npx peer --port 9000`을 실행하고 두 페이지 주소에 `?ps=서버IP:9000`을 붙여 여세요(https가 없으면 `&pss=0`도 붙입니다).
